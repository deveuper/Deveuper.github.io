电脑操作，按需安装

通过 Pi 扩展生态安装或卸载 Computer Use。启用后让 Agent 操作电脑，启用状态与审批方式由你控制。

Pi 上下文与长期记忆

支持上下文扩展与长期指令；长期记忆可编辑、导入或导出，也可按需安装记忆扩展。

一键配置本地 AI

用 Ollama、LM Studio 或 llama.cpp 预设一键填入连接配置，保存后选择模型；使用时需运行对应的本地服务。

多角色 MoA 协作

让你配置的模型分工讨论、互相审查并汇总结果。角色、模型和轮数可调整，消耗取决于任务与所选模型。

熟悉的 Codex 操作方式
