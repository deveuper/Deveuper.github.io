Pi DeveAgent 1.0.21 将本地侧栏热修复纳入公开发行，并隔离终端原生模块的启动故障。

- 左侧栏保持默认或手动拖拽后的宽度；右栏开关、模式切换、窗口大小和缩放不会自动把左栏撑宽。
- node-pty 按需加载；原生模块缺失或不兼容只影响打开终端请求，避免阻断整个桌面启动。
- 工作台与独立官方 Pi 1.0.3 内核分别维护。保留原有模型、API、会话和 MoA 配置。

验证：类型检查、50 项相关单元回归通过；候选和安装后各 3 项真实隐藏 Electron 侧栏回归通过；真实 PowerShell 终端的命令、工作目录和关闭检查通过。安装器已实际解压至中文目录，41,732 文件逐个与审计清单比对。

本版发行包不复制个人模型和账号配置；当前及历史已知个人凭据扫描结果为零。请选择空目录解压，已有配置或文件的目录会拒绝覆盖。更新现有程序前请正常退出，并保留自己的数据目录和旧版回退。

本轮没有新增付费模型验收；复杂国产编码、长期不限轮次 MoA、固定 40% Token 节省仍未验收。

English: This release includes the persistent sidebar width fix and loads native PTY bindings only when a terminal is requested. The independent official Pi core and personal configuration are preserved. Packages contain no personal API configuration. Extract to an empty folder; existing files are protected.
