# Pi Deve Agent 展示页

独立静态网站，默认简体中文，第二语言为英文，另有繁体中文、日、韩、法、德、西、葡、意、俄、阿、印地、印尼、越，共 15 种介绍语言。**软件本身目前只支持简体中文和英文。**

打开 `index.html` 即可预览；也可将整个 `site` 目录上传至静态网站服务。没有构建步骤、外部字体、分析服务或额外依赖。网站文件不包含模型/API 凭据、用户会话或私有路径。

- `product.js`：已核验的公开下载地址与公开网站仓库地址。只有 `publicDownloadVerified` 明确为真且地址属于自己的公开发行仓库，才启用直接下载；未就绪时显示发行入口与准备状态。首页不显示版本号。软件源代码仓库目前私有，公开网站仓库只发布审核过的网站与安装包。
- `locales.js`：全部页面文案；`?lang=en&theme=dark` 可直接指定语言和配色，切换保留当前锚点。
- `references.html`：中性列出参考来源和原许可入口；不显示鸣谢、个人作者主页或背书。旧链接 `acknowledgements.html` 保留相同内容，避免历史链接失效。
- `assets/workspace-*.png`、`assets/moa-settings.png`：实际桌面拍摄，使用独立演示配置，无个人模型、会话或认证信息。
- 八种网页配色只用于预览，不改变软件或用户主题配置，也不承诺软件有八个同名主题。支持减少动画的系统偏好。
- 本地完整安装打开时提供相邻 `../releases/本地版本总览.html` 入口；托管到网上或导出的独立源码副本中隐藏本地入口。`product.js` 的 `localReleaseAvailable` 控制此安装专用入口。网页不启动 EXE 或更改用户设置。

发布整套软件时须保留源码中适用的 `LICENSE`、版权声明和第三方 notices。本目录不会改写任何现有许可，也不声称所有参考项目均采用相同许可。参考来源不表示原项目为本产品背书。

网站已提供 15 种翻译，但不是经母语专业译者逐字审核的商业本地化版本；发布前可继续校对。
